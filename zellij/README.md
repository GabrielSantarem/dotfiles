Minimal `zellij` setup designed to match Helix + Alacritty + Fish.

## What changed

- replaced verbose autogenerated config with a cleaner custom one
- added a minimal default layout
- added a custom green-accent theme
- reduced visual noise in panes and UI
- removed pane frames for a cleaner interface
- switched to an app-first workflow to avoid colliding with Helix keybinds

## Main files

- `zellij/config.kdl`
- `zellij/layouts/default.kdl`
- `zellij/config.kdl.pre-minimal-backup`

## Startup

Default Fish behavior can auto-run:

```sh
zellij attach -c main
```

Manual start:

```sh
zellij
zellij -s main
zellij attach main
```

## Core keybinds

The session starts in **locked** mode by default, so terminal apps like Helix keep their own keybinds.

### Locked mode

- `Ctrl-g` → enter Zellij control mode
- `Ctrl-s` → enter scroll mode directly

### Normal mode

- `Ctrl-g`, `Esc`, `Enter` → return to locked mode
- `p` → pane mode
- `t` → tab mode
- `r` → resize mode
- `m` → move mode
- `s` → scroll mode
- `o` → session mode
- `n` → new pane
- `f` → toggle floating panes
- `[` / `]` → previous/next swap layout
- `q` → quit

### Pane mode

- `h/j/k/l` → move focus
- `;` → last focused pane
- `n` → new pane
- `d` → split down
- `r` → split right
- `f` → fullscreen focused pane
- `F` → fullscreen without UI
- `w` → toggle floating panes
- `z` → toggle pane frames
- `c` → rename pane
- `x` → close focused pane

### Tab mode

- `h/l` or `j/k` → previous/next tab
- `n` → new tab
- `x` → close tab
- `r` → rename tab
- `1..9` → jump to tab

### Scroll mode

- `j/k` → scroll
- `d/u` → half-page down/up
- `h/l` or `PageUp/PageDown` → page scroll
- `s` → search
- `e` → open scrollback in `hx`
- `c` → copy last command output

## UI choices

- simplified UI enabled
- no pane frames
- no rounded corners
- reduced hover effects
- dark background with subtle green accents

## Install / restore

```sh
mkdir -p ~/.config/zellij/layouts
cp zellij/config.kdl ~/.config/zellij/config.kdl
cp zellij/layouts/default.kdl ~/.config/zellij/layouts/default.kdl
```
