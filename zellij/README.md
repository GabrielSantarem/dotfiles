Minimal, high-contrast `zellij` setup designed to match Helix + Alacritty + Fish.

## What changed

- replaced verbose autogenerated config with a cleaner custom one
- enabled native high-contrast `carbon_green` palette matching Alacritty
- enabled discreet, legible UI key helper cheat sheets via `status-bar` and `tab-bar` with `simplified_ui`
- clean startup into default shell by default, with opt-in automation
- removed pane frames for maximum screen estate
- switched to an app-first workflow (`locked` mode default) to avoid colliding with Helix keybinds
- added keybinding to toggle pane input synchronization (`ToggleActiveSyncTab`)

## Main files

- `zellij/config.kdl`
- `zellij/layouts/default.kdl`
- `zellij/layouts/proj.kdl`
- `zellij/config.kdl.pre-minimal-backup`

## Startup

Fish auto-runs, on every interactive local terminal:

```sh
zellij --new-session-with-layout default
```

This always starts a **fresh session with clean panes and a clean shell**.

To auto-start directly into the `proj` project picker layout instead, set:

```fish
set -gx ENABLE_AUTO_PROJ 1
```

Manual start:

```sh
zellij                  # fresh session, default layout
zellij attach <name>    # reattach to a detached session
zellij list-sessions    # see what is still alive
```

## Project workflow

The Fish `proj` helper opens the picked project in a dedicated new tab:

- **Default:** opens a clean shell tab in the project directory
- **Auto-Helix:** set `ENABLE_AUTO_HX=1` (or `AUTO_HX=1` or run `proj --hx`) to open the project in a **dedicated tab running `hx .` full-tab**
  - `:quit` in Helix closes the whole tab and drops you back on the previous tab
  - need a shell in the project? `Alt-f` opens the floating terminal in the project directory

## Session recovery

Context control is fully explicit in this setup:

- **New terminals never restore old context.** Each one starts a fresh session.
- **Session serialization is off** (`session_serialization false` in `config.kdl`), so exited sessions leave no trace and are never resurrected re-running old commands.
- **Accidental closes are still recoverable, on demand.** Closing a terminal window detaches the session; the Zellij server keeps it alive (including pane contents). Recover it manually:

```sh
zellij list-sessions       # detached sessions are still alive
zellij attach <name>       # reattach with full context
zellij kill-session <name> # or discard it
```

## Core keybinds

The session starts in **locked** mode by default, so terminal apps like Helix keep their own keybinds.

### Locked mode

- `Ctrl-g` → enter Zellij control mode (`normal`)
- `Ctrl-s` → enter scroll mode directly
- `Alt-f` → toggle floating terminal (stays in locked mode)

### Normal mode

- `Ctrl-g`, `Esc`, `Enter` → return to locked mode
- `p` → pane mode
- `t` → tab mode
- `r` → resize mode
- `m` → move mode
- `s` → scroll mode
- `o` → session mode
- `n` → new pane
- `f` → toggle floating panes
- `[` / `]` → previous/next swap layout
- `q` → quit

### Pane mode

- `h/j/k/l` → move focus
- `;` → last focused pane
- `n` → new pane
- `d` → split down
- `r` → split right
- `f` → fullscreen focused pane
- `F` → fullscreen without UI
- `w` → toggle floating panes
- `z` → toggle pane frames
- `c` → rename pane
- `x` → close focused pane

### Tab mode

- `h/l` or `j/k` → previous/next tab
- `n` → new tab
- `x` → close tab
- `s` → toggle pane synchronization (Sync Tab)
- `r` → rename tab
- `1..9` → jump to tab

### Scroll mode

- `j/k` → scroll
- `d/u` → half-page down/up
- `h/l` or `PageUp/PageDown` → page scroll
- `s` → search
- `e` → open scrollback in `hx`
- `c` → copy last command output

## Synchronized Panes (Sync Tab)

Synchronized mode replicates keystrokes across all panes within the active tab simultaneously (useful for multi-host SSH or running identical tasks in multiple panes).

- **Toggle via keyboard**:
  1. `Ctrl-g` (enter normal mode)
  2. `t` (enter tab mode)
  3. `s` (toggles sync on/off and returns to locked mode)
- **Toggle via CLI**:
  ```sh
  zellij action toggle-active-sync-tab
  ```

## UI & Theme choices

- **`tab-bar` (top)**: Displays open tabs, index numbers, and active indicator cleanly.
- **`status-bar` (bottom)**: Displays dynamic context-sensitive keybinding cheat sheets.
- **`simplified_ui true`**: Disables bulky Powerline triangles in favor of clean, flat, unobtrusive blocks.
- **High-contrast `carbon_green` palette**: Matches Alacritty's dark background (`#0f1115`), high-contrast text (`#d7dce2`), and green accents (`#42be65`). Automatically inverts selected/highlighted text to dark background (`#1a1d23`) to prevent white-on-white text issues.
- **`pane_frames false`**: Maximizes workspace by omitting bulky frames around panes.

## Install / restore

```sh
mkdir -p ~/.config/zellij/layouts
cp zellij/config.kdl ~/.config/zellij/config.kdl
cp zellij/layouts/default.kdl ~/.config/zellij/layouts/default.kdl
cp zellij/layouts/proj.kdl ~/.config/zellij/layouts/proj.kdl
```
