# About TF

**TF (Terminal Forever)** is just a personal dotfiles setup.

There's no grand manifesto here and nothing to sell. Use whatever tools make you happy—GUI apps, IDEs, or whatever fits your workflow. This project exists simply because building a cohesive terminal environment is fun, challenging, and comfortable to work in every day.

---

## What is in here?

It is essentially a curated collection of modern, fast terminal tools that are pre-configured to work well together:

- **Alacritty**: A clean, GPU-accelerated terminal with dark high-contrast colors.
- **Zellij**: A multiplexer to manage tabs, splits, and floating scratchpad terminals without clashing keybindings.
- **Helix**: A modal text editor with built-in Language Server (LSP) and Tree-sitter support—no complex plugin chains needed.
- **Fish**: A friendly shell with useful aliases, auto-completions, and a minimal prompt.
- **Modern TUIs**: Everyday tools like `lazygit` (Git), `yazi` (file manager), `bottom` (system monitor), and `dust` (disk analyzer).
- **Mise**: Keeps the userland binaries and language servers reproducible across machines.

---

## Why build it?

1. **It's fun to make**: Tweaking terminal tools, writing scripts, and getting things working smoothly is genuinely enjoyable.
2. **Convenience**: Having a single repository or one-liner to set up a new machine with your preferred aliases, keybindings, and tools saves time.
3. **Consistency**: Everything uses a matching dark palette, predictable keyboard shortcuts, and lightweight memory footprints.
